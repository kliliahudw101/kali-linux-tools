▶ 🔍 ما هو WebExtractor؟

WebExtractor هو أداة OSINT مكتوبة بلغة Python لاستخراج المعلومات من المواقع الإلكترونية. تُستخدم في Reconnaissance لجمع Emails، أرقام الهواتف، الروابط، والبيانات المتاحة علنياً.

مستودع WebExtractor على GitHub - أداة OSINT مفتوحة المصدر

🎯 ما يميز WebExtractor

  • ✅ سهولة الاستخدام: واجهة سطر أوامر بسيطة
  • ✅ استخراج متعدد: Emails، Phones، Links، وغيرها
  • ✅ Web Scraping فعال: يستخدم مكتبات Python القوية
  • ✅ كشف البصمة الرقمية: يُظهر ما تكشفه مواقعك
  • ✅ مفتوح المصدر: متاح على GitHub للتعديل والتطوير

🤔 لماذا WebExtractor مهم لاختبار الاختراق؟

الجواب: في مرحلة Information Gathering، تحتاج لجمع أكبر قدر من البيانات عن الهدف. WebExtractor يُسرّع هذه العملية باستخراج معلومات الاتصال (Emails, Phones) التي قد تُستخدم في هجمات Phishing أو Social Engineering. كما يكشف الروابط الداخلية التي قد تحتوي على معلومات حساسة.

💡 مثال عملي: عند اختبار موقع شركة، قد تجد في footer بريداً إلكترونياً للدعم (support@company.com). WebExtractor يستخرجه تلقائياً، وقد تستخدمه لاختبار هجوم Spear Phishing على فريق الدعم.

▶ 🔧 التثبيت والأوامر الأساسية

📥 التثبيت

WebExtractor يتطلب Python 3.x. يمكن تثبيته عبر:

git clone https://github.com/s-r-e-e-r-a-j/WebExtractor.git
cd WebExtractor && pip install -r requirements.txt
واجهة أداة WebExtractor أثناء عملية الاستخراج

🎯 الأوامر الأساسية

python webextractor.py -u https://example.com

يقوم بفحص الموقع واستخراج جميع أنواع البيانات المتاحة.

🤔 ما هو الفرق بين Web Scraping و Web Crawling؟

الجواب: Web Scraping يستخرج بيانات محددة من صفحة واحدة (مثل Emails). Web Crawling يتنقل بين الصفحات ويجمع روابط. WebExtractor يجمع بينهما: يزحف للروابط ويستخرج البيانات من كل صفحة.

🔍 خيارات الاستخدام

python webextractor.py -u https://example.com --emails

يستخرج البريد الإلكتروني فقط.

python webextractor.py -u https://example.com --phones --depth 2

يستخرج أرقام الهواتف مع التعمق في مستويين من الروابط.

▶ 📊 أنواع البيانات المستخرجة

🎯 Emails

يستخدم Regex patterns للعثور على عناوين البريد الإلكتروني:

python webextractor.py -u https://example.com --emails -o emails.txt
عملية استخراج عناوين البريد الإلكتروني من صفحات الويب

🤔 لماذا Emails المستخرجة قد تكون خطرة؟

الجواب: Emails تُستخدم في: 1) هجمات Phishing المستهدفة 2) البحث عن تسريبات البيانات (HaveIBeenPwned) 3) ربط الهويات عبر منصات مختلفة 4) هجمات Credential Stuffing إذا كان البريد مستخدماً كـ username.

📱 Phone Numbers

python webextractor.py -u https://example.com --phones

يستخرج أرقام الهواتف بتنسيقات مختلفة (+1-234-567-8900, (234) 567-8900, إلخ).

🔗 Links

python webextractor.py -u https://example.com --links --external

يستخرج الروابط الخارجية (External Links) التي قد تُشير إلى شركاء أو خدمات طرف ثالث.

🛠️ نصيحة: استخدم --internal للروابط الداخلية فقط لرسم خريطة الموقع (Sitemap).

▶ 🕷️ تقنيات Web Scraping المتقدمة

📜 مكتبات Python المستخدمة

  • requests: لإرسال HTTP requests
  • BeautifulSoup: لتحليل HTML واستخراج البيانات
  • re (Regex): للبحث عن Patterns معينة
  • urllib: لمعالجة الروابط
BeautifulSoup يحلل هيكل HTML لاستخراج البيانات المنظمة

🤔 كيف يتعامل WebExtractor مع حماية المواقع؟

الجواب: يمكن استخدام: 1) User-Agent headers للتمويه كمتصفح حقيقي 2) Delay بين الطلبات لتجنب Rate Limiting 3) Proxy轮换 لتغيير IP 4) التعامل مع JavaScript عبر Selenium (إذا كان الموقع ديناميكياً).

🎯 استخراج Metadata

python webextractor.py -u https://example.com --metadata

يستخرج: Meta descriptions، Keywords، Author names، Generator (CMS used)، وOpen Graph tags.

💡 سيناريو: Metadata قد تكشف: "Generator: WordPress 5.8.1" → تبحث عن ثغرات هذا الإصدار. أو "Author: John Doe" → تبحث عن معلومات John Doe في LinkedIn.

▶ 🌐 التكامل مع أدوات OSINT

📊 التكامل مع theHarvester

تصدير نتائج WebExtractor لاستخدامها في theHarvester:

python webextractor.py -u example.com --emails -o emails.txt && theHarvester -d example.com -f results.html

🤔 ما هو theHarvester وكيف يُكمل WebExtractor؟

الجواب: theHarvester يجمع Emails من محركات البحث (Google, Bing) وShodan, Crt.sh. WebExtractor يجمع من الموقع نفسه. الجمع بينهما يعطي صورة شاملة: البيانات المنشورة على الموقع + البيانات المفهرسة في محركات البحث.

🎯 التكامل مع Maltego

python webextractor.py -u https://example.com --maltego -o maltego.csv

يُنتج ملف CSV يمكن استيراده لـ Maltego لإنشاء Graph بصري للعلاقات.

Maltego يُظهر العلاقات بين الكيانات المستخرجة بصرياً
🛠️ TIP: استخدم WebExtractor للـ Data Gathering، Maltego للـ Visualization، وRecon-ng للـ Automation.

▶ 🛡️ حماية موقعك من Web Scraping

🔒 تقنيات الحماية

  • robots.txt: طلب احترامي للزاحفين (لكن ليس إلزامياً)
  • Rate Limiting: تقييد عدد الطلبات من نفس IP
  • CAPTCHA: اختبارات Turing لمنع البوتات
  • User-Agent Filtering: حظر User-Agents مشبوهة
  • Honeypot Links: روابط خفية للإمساك بالزاحفين
CAPTCHA Challenge لمنع أدوات Scraping الآلية

🤔 هل robots.txt يمنع WebExtractor فعلاً؟

الجواب: لا. robots.txt هو دليل إرشادي (Advisory) وليس قانونياً. أدوات Scraping يمكنها تجاهله. الحماية الحقيقية تكون عبر: Rate limiting، WAF (Web Application Firewall)، وتحليل سلوك المستخدم (Behavior Analysis).

🎯 Obfuscation للبيانات الحساسة

# بدلاً من: contact@example.com # استخدم: contact [at] example [dot] com

أو استخدم صوراً للـ Emails بدلاً من النص (لكن هذا يضر بـ Accessibility).

⚠️ ملاحظة أخلاقية: إذا كنت تختبر موقعاً، تأكد من أن WebExtractor يحترم robots.txt ولا يُثقل load على السيرفر.

▶ 🚀 استخدامات متقدمة و Automation

📜 سكربتات Bash للـ Automation

#!/bin/bash for domain in $(cat domains.txt); do python webextractor.py -u https://$domain --emails -o results/$domain.txt done

فحص قائمة كاملة من المواقع تلقائياً.

🤔 كيف يمكن جدولة WebExtractor لمراقبة موقع دورياً؟

الجواب: استخدم cron jobs (Linux) أو Task Scheduler (Windows). مثال: تشغيل WebExtractor كل يوم الساعة 3 صباحاً لمقارنة النتائج مع اليوم السابق واكتشاف التغييرات (مثل إضافة Emails جديدة).

🎯 التصدير لـ JSON

python webextractor.py -u https://example.com --json -o data.json

🔍 فحص SSL/TLS Certificates

python webextractor.py -u https://example.com --ssl-info
